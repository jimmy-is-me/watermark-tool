# 批次浮水印工具

純前端圖片浮水印工具，支援批次上傳與處理。圖片完全在使用者瀏覽器本地處理，不上傳至任何伺服器。

## 功能

- ✅ 批次上傳圖片（JPG、PNG、WebP、GIF）
- ✅ 文字浮水印 — 可調整字型、大小、顏色、透明度、旋轉
- ✅ 圖片浮水印 — 支援 PNG 透明圖（LOGO）
- ✅ 9 點位置選擇 + 平鋪模式
- ✅ 即時預覽
- ✅ 批次處理 + 打包下載 ZIP
- ✅ 輸出格式：PNG / JPEG / WebP
- ✅ 亮色 / 暗色模式
- ✅ 完全免費，純前端，隱私安全

## 部署到 Cloudflare Pages

1. Fork 或 Clone 本 Repo
2. 前往 [Cloudflare Pages](https://pages.cloudflare.com/)
3. 建立新專案 → 連接 GitHub Repo
4. Build settings：
   - Framework preset: `None`
   - Build command: （留空）
   - Build output directory: `/`
5. 部署完成 🎉

## 本地開發

直接開啟 `watermark-tool.html` 即可，無需安裝任何套件。
